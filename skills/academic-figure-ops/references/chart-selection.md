# 按论证意图选图型

> 选图型的起点不是"哪种图好看"，而是**你要读者相信什么**。
> 同一批数据，图型选错会让结论看起来比实际弱，或者强得站不住。

## 一、先问三个问题（顺序不能颠倒）

1. **读者要做的比较是什么？** 组间 / 时间前后 / 与参考值 / 与理论曲线 / 空间分布
2. **数据量多大？** n 是 3 还是 3000，决定能不能画均值柱
3. **量是连续的还是类别的？** 决定轴线还是色块

答完这三个，图型基本就定了下面某一行。

## 二、决策表

| 论证意图 | 首选 | 备选 | **不要用** |
|---|---|---|---|
| 组间比较（n ≥ 10，有分布） | 箱线图 + 抖动散点 | 小提琴图 | 纯均值柱（丢掉分布） |
| 组间比较（n = 3–8，小样本） | **抖动散点 + 均值±极差/SEM** | 箱线图（n≥5 才用） | **纯均值柱 + 误差棒**（见 §三） |
| 组间比较（只有 2 组 × 1 指标） | 单柱 + 散点 | 水平条形（标签长时） | 饼图 |
| 差异展示（配对/前后） | 配对连线图（slopegraph） | 差值柱 + 0 线 | 双均值柱并列 |
| 随参数变化的趋势 | 折线（点 + 线） | 面积图（强调累积量时） | 柱状图（丢掉连续性） |
| 多指标综合（3–8 个指标 × 多对象） | 雷达图 或 平行坐标 | 热力图（对象多时） | 多个饼图拼贴 |
| 相关关系（两变量） | 散点 + 拟合线 + CI 带 | 六边形分箱（点 > 5000） | 只报 r 值不画图 |
| 相关关系（多变量矩阵） | 下三角散点 + 上三角 r 值 | 相关热力图 | 只放一张 r 矩阵表 |
| 空间分布（二维场） | **填色等值线 + colorbar** | 伪彩图（`pcolormesh`） | 散点（丢空间连续性） |
| 空间分布 + 方向信息 | 填色场 + **流线/箭头**（quiver） | 单独流线图 | 只画箭头不画底场 |
| 构成占比（少数几类） | 堆叠条形 | 百分比堆叠（强调相对量） | **饼图**（>3 类几乎不可读） |
| 时间序列（多条线） | 折线 + 直接标注线名 | 折线 + 图例（≤4 条） | 渐变着色同一线型 |
| 验证（模拟 vs 实测/理论） | 散点 + 1:1 线 + 容差带 | 差值图（残差） | 两条线叠在一起（看不清偏差） |
| 敏感性/稳健性（多参数扫描） | 小多图（small multiples） | 热力图（参数网格） | 一张图堆 20 条线 |

## 三、小样本（n = 3–8）：**别画纯均值柱**

这是结果类章节最容易犯、代价最大的一个错。

**为什么**：3 个样本的均值柱 + 误差棒，看起来像"某组明显更高"，
但 3 个点完全可能是 [1, 1, 9] 和 [4, 5, 3]，均值都是 3.67。
柱子的高度是算出来的，散点的位置是测出来的。**读者要看到测到的点。**

**做法**：

```python
import numpy as np
# 柱 = 均值（浅色填充 + 黑描边）
ax.bar(x, means, width=0.6, facecolor='white', edgecolor='black', linewidth=0.8)
# 误差棒 = 极差 或 ±SEM（n 小用极差更诚实）
ax.errorbar(x, means, yerr=spread, fmt='none', ecolor='black', capsize=3)
# 抖动散点 = 真实测点（关键！）
for i, (xi, ys) in enumerate(zip(x, groups)):
    jitter = np.random.default_rng(0).uniform(-0.12, 0.12, len(ys))
    ax.plot(xi + jitter, ys, 'o', ms=3, color=..., zorder=3)
```

**误差棒写清是什么**：`±SEM` 还是 `±SD` 还是`极差`，写进图注，不许省略。
n 写进图注（`n = 3`）。

**n = 3 时不要报显著性**。统计检验在 n=3 下没有意义，
`***` 标上去是给自己挖坑（评委一问 p 值怎么来的就崩）。

## 四、按章节类型选图（具体到图）

### 已定稿的一组图（作风格基准）

| 图 | 图型 | 值得学的地方 |
|---|---|---|
| 示例 1（ACF/PDF/PSD） | 折线 + 双对数轴 | 三物理量同框，用分幅而非双 y 轴 |
| 示例 2（验证总图） | 4 分幅：(a) 散点+1:1+±2%带 (b) 柱状 (c) 柱状+参考虚线+±15%带 (d) 折线+±20%带 | **验证类图的教科书排版**：(a) 给"整体对不对"，(b)(c)(d) 给"每一项对不对" |
| 示例 3（变差函数） | 折线 + 分箱点 | 变差函数必须标分箱数，箱太粗曲线会假平滑 |
| 示例 4（分布形态） | 直方图 + 拟合曲线 | 分布形态用直方图，不用均值柱 |
| 示例 5（控制变量） | 多分幅等高线 | 控制变量的效果用空间场展示，比列表直观 |

### 数值方法类章节

需要的图型：
- **方法流程示意**（不是数据图）→ 纯 matplotlib 画方框 + 箭头，或 TikZ；
- **网格/几何示意** → `tricontourf` 或直接画剖面；
- **模型验证**（与解析解比）→ 折线 + 理论曲线 + 误差副图。

### 结果类章节（CFD 主战场）

| 要说明的事 | 图型 | 要点 |
|---|---|---|
| 相界面推进形态随时间演化 | **多分幅填色云图**（4–6 个时刻）+ 统一 colorbar | 各分幅色标必须一致，否则看不出推进 |
| 速度场 + 流动方向 | 填色场 + quiver 箭头（降采样） | 箭头过密会糊，`quiver(..., stride)` 抽稀 |
| 压力分布 | 填色等值线 + 白色等值线叠加 | 等值线间距要标出来 |
| 剖面沿程变化 | 折线（沿程距离 vs 量） | 多时刻多条线，用 `INK_SEQ` 顺序色 |
| 参数敏感性 | 小多图（3×3）+ 统一坐标范围 | **各分幅轴范围必须一致**，否则结论是假的 |
| 与文献对标 | 折线 + 文献散点 | 文献点用不同 marker，图注标出处 |

## 五、分幅（多子图）的规矩

1. **标号 `(a)(b)(c)` 写在坐标区下方**，不写进 `title`（`figstyle.panel` 已实现）。
2. **同组比较的分幅，轴范围必须一致**。不一致会让人误判量级（这是结果类章节的头号风险）。
3. **共享 colorbar 时**，只在最右/最下列画一个，范围由全部数据决定。
4. **分幅数量**：4 分幅（2×2）或 6 分幅（2×3）最好读；**超过 9 个改用小多图+索引**。
5. **只在必要处加轴标签**：共享 x 轴的列，只有最下面一行标 x；共享 y 轴的只有最左一列标 y。
   （常见坑：多子图轴名连成 `x / mmy / mm`，就是没做这个。）

## 六、colorbar 的规矩

- 必须有 **label**（写物理量 + 单位：`速度 / (m·s⁻¹)`）；
- 发散量（有正负）→ **对称范围 + 0 在中点**（`vmin=-v, vmax=v`），否则颜色不对称会误导；
- 顺序量 → 不要对称，用数据的真实 min/max；
- 同一系列分幅 → **共用一个 colorbar 对象**，别每个分幅各自归一化；
- colorbar 宽度不要吃掉坐标区：`fraction=0.046, pad=0.04` 是安全值。

## 七、什么时候该换思路（不是换图型）

| 现象 | 说明什么 | 怎么办 |
|---|---|---|
| 图里塞了 5 个分幅还看不清 | 信息太多 | 拆成两张图，正文各讲一件事 |
| 需要 3 层图例才解释得清 | 编码过载 | 减类别，或改小多图 |
| 要用双 y 轴才放得下 | 两个量量纲不同且要比较趋势 | **拆成上下两个分幅共享 x 轴** |
| 读者要放大 400% 才能看见差别 | 量级差太大 | 改对数轴，或画残差/比值副图 |
| 得靠图注写 5 行才说得清 | 图没自明 | 重画，不是加图注 |
